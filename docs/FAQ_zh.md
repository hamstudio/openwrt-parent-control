## 1. Web 界面与 LuCI 相关

### Q1.1: 在 HTTPS 访问 LuCI 时，内嵌控制台报错“发生 SSL 错误 / 证书无效”怎么办？

#### 💡 原理解析
当您通过 `https://192.168.0.110/` 访问 OpenWrt LuCI 后台时，浏览器仅对 **443 端口** 授予了自签名证书的访问信任。
由于 ParentControl Guard 运行在独立端口（`8089 HTTPS` / `8088 HTTP`），浏览器出于安全沙箱机制，**绝不会在后台 iframe 内部弹出“是否信任证书”的提示**，因此会直接拦截并抛出 SSL 错误。

#### 🛠️ 解决方案（二选一）：
- **方案 A（一键授权，iframe 永久正常，推荐）**：
  在新标签页中打开一次：`https://192.168.0.110:8089`，在浏览器弹出的安全提示中点击 **“高级” -> “继续前往 192.168.0.110 (不安全)”**。授权完成后返回 LuCI 刷新页面，内嵌面板即可永久正常显示。
- **方案 B（免证书验证，全屏极速体验）**：
  直接在 LuCI 顶部点击 **`[HTTP 直连 (:8088)]`** 或 **`[↗ 新窗口全屏打开控制台]`** 按钮，新标签页全屏使用，体验更佳。

---

### Q1.2: 页面出现空白或某些按钮无响应怎么办？
请尝试按键盘快捷键 `Ctrl + F5`（Windows）或 `Cmd + Shift + R`（Mac）强制刷新浏览器缓存。系统前端支持 8 种语言热切换与防崩兜底，强刷后即可重新加载最新的 `i18n.js` 与交互脚本。

---

### Q1.3: 忘记了 4 位数管理员 PIN 访问密码怎么办？
通过 SSH 登录路由器终端，执行以下命令即可一键清空密码锁并重启服务：
```bash
# 1. 清空配置文件中的 PIN 码
sed -i 's/"pin_code": "[^"]*"/"pin_code": ""/g' /etc/parentcontrol/config.json

# 2. 重启服务使之生效
/etc/init.d/parentcontrol restart
```

## 2. 策略控制与时间调度

### Q2.1: 如何配置多个自定义禁网时间段（例如中午 + 晚上跨夜）？
1. 在控制台点击目标家庭成员卡片右上角的 **⚙️ (编辑规则)**；
2. 找到 **【时间限制与禁网时间表】** 区域，确保勾选了 **“启用时间表”**；
3. 选择生效星期（支持点击“每天”、“工作日”、“周末”快捷多选）；
4. 在时间段列表中点击 **`+ 添加时间段`** 按钮，可以自由添加多组时间（例如 `12:30 - 13:30` 以及跨夜的 `21:30 - 07:00`）；
5. 点击 **【保存规则】** 即可立即下发内核生效。

---

### Q2.2: 设备列表里的“一键断网”与“成员一键断网”有什么区别？
- **成员一键断网**：切断该家庭成员名下的**所有绑定设备**（如孩子的手机 + 平板 + 笔记本）。
- **设备列表一键断网**：对局域网中**特定的单个 MAC 地址**进行独立的临时隔离/放行，无论该设备是否已分配给成员均可秒级生效。

---

### Q2.3: 奖励加时（Bonus Time）是如何生效的？
当成员当天的配额已耗尽或正处于禁网时间段时，家长可以点击成员卡片上的 **`+ 奖励加时`** 按钮，选择 `+15分钟`、`+30分钟`、`+1小时` 或 `+2小时`。
系统会自动赋予该成员限时临时上网豁免权，倒计时结束后自动恢复常规管控。

## 3. DPI 特征库与应用封禁

### Q3.1: 提示“kmod-oaf 未加载 (规则降级)”是什么意思？
ParentControl Guard 的深度应用封禁依赖 OpenWrt 内核级 `kmod-oaf` 模块。
如果您的路由器固件未预装该内核模块，系统会自动**平滑降级**为基于域名（DNS）和 IP/端口过滤的基础安全模式，一键断网、时间配额、DoH 阻断和 SafeSearch 依然完全正常工作。

---

### Q3.2: 为什么封禁某些 App 后，孩子换了手机 MAC 还是能上网？
部分现代手机（iOS / Android）开启了“专用无线局域网地址（MAC 地址随机化）”。
#### 💡 防御方案：
进入 **【全局安全配置】** Tab，开启 **“新设备防随机化隔离 (MAC 随机化防御)”** 开关。开启后，任何新随机生成的未知 MAC 地址连入路由器默认均无法上网，必须由家长在控制台中审批分配后方可通行。

---

### Q3.3: 如何自定义新增特征库中没有的冷门游戏或应用？
1. 进入 **【特征库管理 (DPI)】** Tab；
2. 点击右上角 **`+ 添加应用`**；
3. 输入应用名称、所属分类以及应用描述；
4. 点击保存后，新应用特征立即入库，并自动同步到所有成员的封禁勾选列表中。

## 4. 公网远程控制与跨网同步

### Q4.1: 手机在 4G/5G 外网环境下如何远程管控家里的路由器？
系统支持通过 **Cloudflare Worker** 作为安全的无服务器中继：
1. 按照 `cloud/cloudflare-worker/README.md` 在 Cloudflare 免费部署专属 Worker；
2. 在路由器的 **【全局安全配置】** 中填入 Worker URL 与通信 Secret 并开启同步；
3. 手机 App 填入相同 Worker 地址即可随时随地跨公网查看状态、一键断网或奖励加时。

---

### Q4.2: 路由器主动出站同步安全吗？会暴露内网端口吗？
**绝对安全**。路由器内部的 `CloudSyncer` 守护进程仅发起**主动出站（Outbound）** HTTPS 请求轮询 Cloudflare 中继队列，**无需路由器具备公网 IP，也无需在光猫/路由器上做任何危险的端口映射（Port Forwarding）**，杜绝公网黑客扫描内网的风险。
