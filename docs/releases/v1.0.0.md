# 🛡️ ParentControl Guard v1.0.0 官方正式版发布说明

> **基于 Go 与 Linux 内核级 DPI 的 OpenWrt 细粒度家长控制与上网行为管理系统**

ParentControl Guard 迎来首个官方正式版本 **v1.0.0**！本版本提供完整的路由器端守护进程、内核级 DPI 应用过滤、多层防代理绕过防火墙、时长行为统计大屏、LuCI 管理面板以及原生 Android / iOS 移动端客户端。

---

## 🌟 核心功能亮点 (Highlights)

### 1. 🎮 内核级 L7 DPI 深度包检测与应用精准识别
- 基于 `kmod-oaf` 字符设备与特征库，在协议层深度解析数据包；
- 预置 **8 大分类**（网络游戏、短视频、社交聊天、网络购物、影音播放、下载工具、学习办公、其他工具）以及数百款国内与国际主流应用（王者荣耀、和平精英、原神、Steam、抖音、快手、TikTok、YouTube、B站、Discord 等）；
- 支持按家庭成员粒度勾选一键封禁指定分类或指定 App。

### 2. ⏱️ 多时间段规则、周天预设与活跃限额 (Token Bucket)
- 支持为家庭成员绑定多台设备（手机、平板、电脑、智能手表）；
- 支持 **多时间段组合禁网计划**，原生支持跨夜时段（如 `22:00 ~ 09:00`）；
- 支持快捷工作日、周末或自定义周天计划预设；
- 独创 **人机交互流量计量算法**（过滤 15KB/s 以下的休眠推送与物联网心跳底噪），真实统计有效上网时间；
- 支持 **一键断网 (Instant Lock)** 与 **临时奖励加时 (+15m / +30m / +1h)**。

### 3. 🛡️ 立体多层防绕过与安全搜索防护体系
- **Mangle 表 PREROUTING 第一优先级截杀**：规则置于网络协议栈最顶端，彻底解决安装 OpenClash / Passwall / SSR+ 等透明代理软件时禁网规则被旁路绕过的问题；
- **SafeSearch 强制启用**：锁定 Google、Bing、Baidu、YouTube 青少年安全搜索；
- **全网防窜改**：53 端口强制重定向本地，封锁外部公共 DoH / DoT (853 / 443 端口)，杜绝私自修改 DNS 绕过监管。

### 4. 📊 24 小时活跃时长与行为画像统计
- 自动生成每台设备的 **24 小时活跃分布柱状图**（标记夜间活跃区间）；
- 统计 **DPI 访问分类占比** 与 **Top 热门应用使用排行**；
- 提供 **7 天与 30 天历史使用趋势图**，支持日报表自动归档。

### 5. ☁️ 双模式云端远程中继 (无需公网 IP)
- **Cloudflare Workers & KV**：出站 HTTPS 长轮询无服务器中继，全球边缘节点加速；
- **独立 Go Relay Server**：支持自建国内 VPS 部署，基于 In-Memory PubSub 消息队列与 WebSocket 实时双向推送，解决部分网络环境下访问 CF 缓慢的问题。

### 6. 📱 全平台客户端矩阵
- **单二进制内嵌 Web 控制台**：`:8088` HTTP / `:8089` HTTPS 双端口监听，原生集成进 LuCI，自适应手机与桌面浏览器，内置 8 国语言与 4 位数字 PIN 安全锁屏；
- **Android 原生客户端**：基于 Kotlin + Jetpack Compose 打造的 Material 3 现代化移动端；
- **iOS 原生客户端**：基于 SwiftUI 打造，共享 Swift 跨平台核心业务层。

## 📥 安装与升级指南

### 1. 路由器端安装
将对应架构的 `.ipk` 上传到路由器 `/tmp/` 目录，执行以下命令：

```bash
# 1. 预先安装依赖内核模块与工具
opkg update
opkg install kmod-oaf iptables-mod-ipopt iptables-mod-conntrack-extra

# 2. 安装 ParentControl Guard (以 x86_64 为例)
opkg install /tmp/luci-app-parentcontrol_1.0.0-1_x86_64.ipk

# 3. 启动并启用开机自启
/etc/init.d/parentcontrol enable
/etc/init.d/parentcontrol start
```

安装完成后，刷新 OpenWrt LuCI 界面，可在 **「服务 / Services」➔「家长控制 / Parent Control」** 中直接进入现代化管理面板（默认独立端口为 `http://路由器IP:8088`）。

### 2. 初始安全密码
- **默认 PIN 密码**：`6498`（首次登录后可在「全局设置」中修改）。
