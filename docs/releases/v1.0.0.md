# 🛡️ ParentControl Guard v1.0.0 Official Release

> **Fine-grained Parental Control & Internet Activity Management for OpenWrt, powered by Go and Kernel-Level DPI (`kmod-oaf`).**

We are thrilled to announce the first official general availability release: **v1.0.0**! 

**ParentControl Guard** provides an enterprise-grade, lightweight, and modern parental control solution designed specifically for OpenWrt routers, x86_64 gateways, and embedded hardware.

---

## 🌟 Key Highlights & Features

### 1. 🎮 Kernel L7 Deep Packet Inspection (DPI)
- Powered by the `kmod-oaf` kernel module for real-time protocol and signature analysis at wire speed with minimal CPU overhead.
- Built-in signatures covering **8 major categories** and hundreds of popular applications (Steam, TikTok, YouTube, Discord, Honor of Kings, Genshin Impact, Bilibili, and more).
- Per-member granular application and category blocking.

### 2. ⏱️ Multi-Schedule Rules & Human-Active Quota
- Combine multiple customized time slots per day with full support for overnight spans (e.g., `22:00 ~ 09:00`).
- Flexible weekday/weekend presets and custom scheduling.
- **Human-Active Traffic Filtering (15 KB/s threshold)**: Distinguishes genuine interactive screen time from background device noise (Apple APNs, Google FCM push notifications, IoT keepalives, and NTP).
- **1-Click Instant Lock** & **Bonus Time Extension (+15m / +30m / +1h)** for temporary parental rewards.

### 3. 🛡️ Multi-Layer Anti-Bypass & SafeSearch Enforcement
- **Top-Priority `mangle` PREROUTING Interception**: Position 1 packet dropping before any proxy engine (OpenClash, Passwall, SSR+) or NAT translation, completely preventing proxy bypass.
- **Forced SafeSearch**: Enforced on Google, Bing, Baidu, and YouTube.
- **Anti-DNS Tampering**: Outbound Port 53 redirected to local DNS; blocked public DoH/DoT resolvers (ports 853 / 443) and MAC randomization detection.

### 4. 📊 24-Hour Usage Analytics & Profiling
- Real-time 24-hour activity distribution histograms with late-night indicators.
- DPI category breakdown and top application rankings.
- 7-day and 30-day historical trend analysis with automatic daily archiving.

### 5. ☁️ Dual-Mode Remote Cloud Relay (No Public IP Needed)
- **Cloudflare Workers & KV**: Zero-maintenance serverless long-poll relay for out-of-home remote control.
- **Standalone Go Relay Server**: Self-hostable on any private VPS, equipped with an in-memory PubSub MQ and WebSocket bidirectional real-time streams.

### 6. 📱 Cross-Platform Ecosystem
- **Embedded Web Dashboard**: Dual HTTP (`:8088`) and HTTPS (`:8089`) listeners, native LuCI view embedding, mobile-first responsive layout, 4-digit PIN security lock, and 8 localized languages.
- **Native Android App**: Modern Material 3 interface built with Kotlin and Jetpack Compose.
- **Native iOS App**: SwiftUI application sharing a high-performance cross-platform Swift core (`ParentControlCore`).

## 📥 Quick Installation & Setup

### 1. Router Installation
Upload the corresponding `.ipk` package to your router's `/tmp/` directory, then execute:

```bash
# 1. Update package feeds and install prerequisites
opkg update
opkg install kmod-oaf iptables-mod-ipopt iptables-mod-conntrack-extra

# 2. Install ParentControl Guard (example for x86_64)
opkg install /tmp/luci-app-parentcontrol_1.0.0-1_x86_64.ipk

# 3. Enable and start the service
/etc/init.d/parentcontrol enable
/etc/init.d/parentcontrol start
```

After installation, refresh your LuCI interface and navigate to **Services ➔ Parent Control** or open `http://<Router-IP>:8088/` directly in any web browser.

### 2. Default Access Credentials
- **Default PIN Code**: `6498` (Can be modified at any time in *Global Settings*).
