# 🛡️ ParentControl Guard v1.0.1 Official Release

> **Patch release addressing kernel-level traffic accounting accuracy, idle sleep filtering, and quota release logic.**

We are pleased to release **v1.0.1** with critical bug fixes and precision enhancements to the traffic metering and quota management subsystems.

---

## 🛠️ What's Changed in v1.0.1

### 1. ⚡ Kernel-Level `PARENT_CONTROL_ACCT` Traffic Accounting
- Replaced connection-based conntrack byte delta summation with a dedicated Linux kernel Netfilter accounting chain (`PARENT_CONTROL_ACCT`).
- Provides strictly monotonic, packet-accurate physical byte counters across both ingress (Rx) and egress (Tx) directions.
- Completely eliminates false traffic spikes caused by TCP connection creation, keepalive resets, and idle connection expirations.

### 2. 🌙 Precision Idle Device Sleep Filtering (150 KB/min Threshold)
- Introduced an aggregate 150 KB/minute activity threshold (`MinActiveMinuteBytes`).
- Device background activity (e.g. Apple APNs, Google FCM push notifications, NTP synchronization, smart speaker/TV cloud heartbeats) is now 100% distinguished from genuine interactive screen time.
- Guarantees zero false usage minutes during late-night idle and standby periods.

### 3. 🔓 Robust Quota Exemption & Form State Preservation
- Enhanced `shouldBlockMember` policy evaluation: whenever a member's management is disabled (`Enabled == false`) or `QuotaMinutes <= 0`, access is unconditionally permitted and firewall block rules are instantly cleared.
- Fixed the Web dashboard modal form to properly preserve the active `enabled` state instead of forcing `enabled: true` upon editing rules.
- Added automatic persistence of daily reset state to disk.
